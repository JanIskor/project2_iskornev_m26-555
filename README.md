## Описание

Консольное приложение на Python для управления простой базой данных.

Программа позволяет создавать таблицы, добавлять, просматривать, изменять
и удалять записи. Метаданные и содержимое таблиц сохраняются в JSON-файлах.

Дополнительно реализованы:
- проверка типов данных;
- обработка ошибок;
- подтверждение удаления;
- измерение времени выполнения операций;
- кеширование результатов выборки.

## Требования

- Python 3.12 или новее;
- менеджер зависимостей `uv`.

После запуска отображается приглашение:

***База данных***

Для просмотра списка команд введите `help`, для завершения работы — `exit`.

## Доступные команды

| Команда | Назначение |
|---|---|
| `help` | Показать справку |
| `exit` | Завершить программу |
| `create_table <имя> <столбец:тип> ...` | Создать таблицу |
| `list_tables` | Показать все таблицы |
| `drop_table <имя>` | Удалить таблицу |
| `insert into <имя> values (...)` | Добавить запись |
| `select from <имя>` | Показать все записи |
| `select from <имя> where <столбец> = <значение>` | Выбрать записи по условию |
| `update <имя> set <столбец> = <значение> where <столбец> = <значение>` | Обновить записи |
| `delete from <имя> where <столбец> = <значение>` | Удалить записи |
| `info <имя>` | Показать структуру таблицы и количество записей |

## Пример использования

Ниже приведён полный сценарий работы с таблицей `users`.

### 1. Создание таблицы

```text
create_table users name:str age:int is_active:bool
```

Результат:

```text
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool
```

Столбец `ID` типа `int` добавляется автоматически.

### 2. Добавление записей

```text
insert into users values ("Иван", 22, true)
insert into users values ("Анна", 24, false)
```

Пример результата:

```text
Запись с ID=1 успешно добавлена в таблицу "users".
```

ID новой записи определяется автоматически как максимальный существующий
ID плюс один.

### 3. Просмотр записей

Вывести все записи:

```text
select from users
```

Выбрать записи по условию:

```text
select from users where age = 22
```

Результаты отображаются в виде таблицы с помощью `PrettyTable`.

### 4. Обновление записи

```text
update users set age = 23 where ID = 1
```

Результат:

```text
Запись с ID=1 в таблице "users" успешно обновлена.
```

Изменение значения `ID` запрещено.

### 5. Удаление записи

```text
delete from users where ID = 2
```

Перед удалением программа запрашивает подтверждение:

```text
Вы уверены, что хотите выполнить "удаление записей"? [y/n]:
```

Введите `y`, чтобы подтвердить операцию, или `n`, чтобы отменить её.

### 6. Информация о таблице

```text
info users
```

Команда выводит название таблицы, типы столбцов и количество записей.

### 7. Список таблиц

```text
list_tables
```

### 8. Удаление таблицы

```text
drop_table users
```

Удаление выполняется после подтверждения пользователя. Вместе с
описанием таблицы удаляется соответствующий JSON-файл.

## Типы данных

Поддерживаются три типа:

| Тип | Пример | Правило |
|---|---|---|
| `int` | `25` | Целое число без кавычек |
| `str` | `"Иван Петров"` | Строка в двойных кавычках |
| `bool` | `true` | Логическое значение без кавычек |

Значения `true` и `false` можно вводить в любом регистре.

При добавлении записи необходимо передать значения всех пользовательских
столбцов в порядке их объявления. `ID` указывать не нужно.

Названия таблиц и столбцов чувствительны к регистру. Допустимы латинские
буквы, цифры и символ `_`, но название не может начинаться с цифры.

## Хранение данных

Приложение использует JSON-файлы:

```text
db_meta.json
data/
    users.json
```

- `db_meta.json` хранит названия таблиц и типы столбцов.
- `data/<имя_таблицы>.json` хранит записи соответствующей таблицы.
- Отсутствующий файл данных обрабатывается как пустая таблица.
- При удалении таблицы её файл данных удаляется.

Файлы пользовательской базы данных исключены из Git.

## Декораторы и кеширование

В приложении реализованы следующие механизмы:

- `handle_db_errors` — обработка ошибок `KeyError`, `ValueError`
  и `FileNotFoundError`;
- `confirm_action(action_name)` — подтверждение удаления таблиц и записей;
- `log_time` — измерение времени выполнения `INSERT` и `SELECT`;
- `create_cacher()` — замыкание для кеширования результатов `SELECT`.

Повторная выборка с теми же параметрами использует кеш.

После успешных команд `insert`, `update`, `delete` и `drop_table`
кеш сбрасывается, чтобы не возвращать устаревшие данные.

## Структура проекта

```text
src/primitive_db/
    __init__.py
    main.py
    engine.py
    core.py
    parser.py
    decorators.py
    utils.py
    constants.py
```

Назначение модулей:

- `main.py` — точка входа;
- `engine.py` — обработка команд и взаимодействие с пользователем;
- `core.py` — логика работы с таблицами и записями;
- `parser.py` — разбор введённых команд;
- `decorators.py` — декораторы и кеширующее замыкание;
- `utils.py` — чтение и запись JSON-файлов;
- `constants.py` — константы приложения.
